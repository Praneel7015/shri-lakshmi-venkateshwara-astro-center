# Ornament tiles

`public/ornaments/stars-light.svg` and `stars-night.svg` are generated by `make_tiles.py` (this folder).

- Sparkles, dots and the constellation are drawn in code for this site.
- The zodiac signs (♈ ♌ ♐ ♓) are outlines traced from **MesloLGM Nerd Font**: Meslo LG is Apache 2.0, the Nerd Fonts patches are MIT, and its zodiac glyphs come from **DejaVu** (Bitstream Vera licence plus public-domain changes). All permit this use.

Both files are single-colour and used as CSS masks (`mask: url(...)`) in `src/app/globals.css`. The colour comes from the theme tokens (`stars`, `stars-night`, `bg-sky` utilities), so they never need editing for a palette change.
